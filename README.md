# 📦 Supply Chain Dashboard | Power BI

An interactive **Supply Chain Dashboard** built in **Power BI** to monitor key supply chain KPIs, evaluate logistics performance, and provide actionable insights across warehouses, transportation modes, and regions.

This project demonstrates the use of **Power BI, Power Query, DAX, data modeling, and interactive visualizations** to transform raw supply chain data into a comprehensive business intelligence dashboard.

---

## 📌 Project Overview

The objective of this project was to create a centralized dashboard that enables businesses to monitor order fulfillment, evaluate delivery performance, analyze warehouse efficiency, and identify operational bottlenecks.

The dashboard provides real-time visibility into supply chain metrics, helping stakeholders make informed, data-driven decisions.

---

## 🎯 Business Questions Answered

This dashboard answers the following business questions:

- How many total orders have been processed?
- What is the Overall OT (On-Time Delivery) percentage?
- What is the Overall IF (In-Full Delivery) percentage?
- What is the Overall OTIF (On-Time In-Full) percentage?
- Which regions have the highest OTIF performance?
- How do OT and IF percentages compare across different regions?
- How has OTIF performance changed over time?
- Which warehouse locations experience the highest average delivery delays?
- Which transport mode has the highest average delay?
- How does the ordered quantity compare with the delivered quantity over time?
